项目描述：实现了一个即时通信系统，支持多用户实时聊天、私聊、消息广播等功能。
技术栈：Gin + WebSocket + Goroutine + Redis + MySQL
详细介绍：
	高并发通信模型：基于Gin接入WebSocket协议实现双向长连接；深入应用Go并发特性，为每个连接分配独立的读写Goroutine，并利用缓冲Channel与select机制平衡消息的生产与消费速率，保障高并发场景下的系统吞吐量与稳定性 。
	连接管理与高可用：自主设计在线连接池模块，采用sync.RWMutex读写锁保障并发环境下的状态安全；实现Ping/Pong心跳检测与超时剔除机制，自动清理异常断开的连接，防止服务器资源泄漏。
	异步消息持久化：为解决海量消息直接落库带来的主链路阻塞问题，设计了轻量级异步任务池，将聊天记录异步批量写入MySQL，大幅提升了消息的分发效率与系统响应比。
